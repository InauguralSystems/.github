# Security Policy

This is the default security policy for every InauguralSystems repository that does not have its own `SECURITY.md`. A repository's own policy, where present, takes precedence.

## Reporting a vulnerability

Please report security issues privately rather than in a public issue. You can either:

- use **GitHub private vulnerability reporting** on the affected repository (Security tab → *Report a vulnerability*), or
- email **contact@inauguralsystems.com** with the subject prefix `[SECURITY]`.

Include the affected repository and commit, steps or an input to reproduce, and what you observed.

## Scope

- Issues in the EigenScript interpreter, runtime, JIT or standard library belong to the [EigenScript](https://github.com/InauguralSystems/EigenScript) repository, which has its own security process.
- Each other repository covers its own sources and the inputs it reads.

## Supported versions

The latest commit on each repository's default branch is supported.
